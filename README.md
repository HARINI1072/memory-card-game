# Memory Match – Card Matching Game

## Project Description
Memory Match is an interactive card matching game developed using HTML, CSS and JavaScript. Players flip cards to find matching pairs and improve their memory skills.

## Features
- Three difficulty levels: Easy, Medium and Hard.
- Multiple levels in each difficulty.
- Normal Mode and Challenge Mode.
- Timer and moves tracking.
- Best score tracking.
- Sound effects.
- Smart Hint System.
- Pause and Resume functionality.
- Daily streak and progress tracking.
- Responsive design for mobile and desktop devices.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Local Storage
- GitHub Pages

## How to Play
1. Open the game using the live demo link.
2. Choose a difficulty level.
3. Select a game mode.
4. Flip the cards and find matching pairs.
5. Complete all pairs to win!
